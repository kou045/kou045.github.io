Privacy Policy

Last updated: November 15, 2026

What this app is

Stella Aube YouTube Tool is a private tool used only by Stella Aube to manage its own YouTube channels. It is not offered to the public.

Data the app accesses

With the channel owner's permission (Google OAuth, scope youtube.force-ssl), the app accesses only the owner's own channels: video titles and descriptions, public statistics such as view and subscriber counts, and comments posted on those channels.

How the data is used

The data is used only to understand the channels' performance, to update the titles, descriptions, captions and audio language of the channels' own videos, and to write and post replies to comments on those channels. Comment text may be sent to Anthropic's Claude API to draft replies. The data is not sold, not shared for advertising, and not used for any other purpose.

Storage

Access tokens are stored only on the owner's own computer. Summaries may be kept on that computer for the channel's records. No data is stored on a public server.

Google API Services

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time from Google Account permissions.
