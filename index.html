Stella Aube YouTube Tool

Stella Aube YouTube Tool is a private tool used only by Stella Aube to manage its own YouTube channels.

It reads the channels' own videos, statistics and comments, updates the titles, descriptions, captions and audio language of the channels' own videos, and posts replies to comments on those channels. Comment text may be sent to Anthropic's Claude API to draft replies. It is not offered to other users.

Stella Aube YouTube Tool は、Stella Aube が自分の YouTube チャンネルを運営するためだけに使う、社内用の道具です。自分のチャンネルの動画・数字・コメントを読み、自分の動画の題名・説明欄・字幕・音声の言語を更新し、そのチャンネルのコメントに返事をします。返事の下書きのため、コメントの文を Anthropic の Claude API に送ることがあります。ほかの人には提供していません。
